# ADR-0003: Motor lógico primero en modo sombra

Estado: propuesto para aprobación en Rama 0.

## Decisión

Las reglas organizacionales se expresarán como hechos y reglas verificables. El motor lógico comparará su decisión con las políticas Go antes de bloquear acciones. No reemplazará el camino crítico hasta alcanzar paridad sobre un corpus de tráfico y pruebas.

## Alcance inicial

Existencia de roles, liderazgo, rutas de mensajes, delegación, capabilities y dependencias. La verificación de afirmaciones mediante tableaux será una fase posterior.
